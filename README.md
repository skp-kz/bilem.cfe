# bilem.cfe

Расширение для **1С:Бухгалтерии для Казахстана 3.0**, через которое ИИ-ассистент [Bilem.ai](https://bilem.ai) работает с вашей базой по протоколу [MCP](https://modelcontextprotocol.io): отвечает на вопросы по учёту, находит данные, готовит черновики документов.

> **Bilem не влияет на учёт.** Расширение только читает данные и создаёт непроведённые документы. Оно не проводит документы, не делает платёжки, ПКО/РКО и не закрывает месяц. Привилегированный режим не используется: агенту доступно ровно то, что разрешают ему роли в вашей 1С.

**Статус: ранняя версия 0.1.0.** Есть один инструмент — `whoami` для проверки подключения. Инструменты работы с учётом добавляются по мере готовности, см. [CHANGELOG](CHANGELOG.md).

## Как это работает

```
Claude / ChatGPT / Bilem.ai ──MCP (HTTPS)──▶ веб-сервер 1С ──▶ HTTP-сервис расширения bilem ──▶ ваша база
```

- Расширение добавляет в конфигурацию HTTP-сервис `bilem` и роль `Bilem_Агент`. Типовую конфигурацию не меняет и снимает с поддержки ничего не нужно.
- Запросы выполняются от отдельного пользователя 1С, права которого вы настраиваете сами.
- Доступ к MCP защищён токеном. Токен хранится в базе в константе `BilemТокен`.

## Требования

- 1С:Предприятие 8.3.27 или новее (проверено на 8.3.27.2342).
- 1С:Бухгалтерия для Казахстана, редакция 3.0 (проверено на 3.0.73.1).
- Веб-сервер с публикацией HTTP-сервисов: IIS или Apache.

## Установка

1. **Расширение.** Конфигуратор → Конфигурация → Расширения конфигурации → Добавить из файла → `bilem.cfe`. Затем «Обновить конфигурацию базы данных». Расширение собирается из выгрузки в папке `src/`.
2. **Пользователь.** Создайте пользователя 1С, например `bilem`: вход только по паролю, без показа в списке выбора. Назначьте ему роль `Bilem_Агент` и роли на чтение тех разделов учёта, которые агенту разрешено видеть.
3. **Токен.** Сгенерируйте случайную строку из 64 символов (hex) и запишите её в константу `BilemТокен`: Все функции → Константы.
4. **Публикация.** Администрирование → Публикация на веб-сервере. Включите только «HTTP-сервисы» и «HTTP-сервисы расширений». Веб-клиент, OData и web-сервисы для этой публикации не нужны. Для вызовов API укажите в публикации пользователя из шага 2.
5. **Проверка.**
   ```
   GET  https://<ваш-сервер>/<публикация>/hs/bilem/whoami     заголовок X-Bilem-Token: <токен>
   POST https://<ваш-сервер>/<публикация>/hs/bilem/mcp/<токен> {"jsonrpc":"2.0","id":1,"method":"tools/list"}
   ```
   Ответ `whoami` — пользователь, организация, версии конфигурации, платформы и расширения.

## Подключение к ассистенту

Адрес MCP-сервера: `https://<ваш-сервер>/<публикация>/hs/bilem/mcp/<токен>`.

- **Claude:** Settings → Connectors → Add custom connector → адрес выше, без входа (No sign-in).
- **Claude Code:** запись в `.mcp.json` с типом `http`. Токен подставляйте из переменной окружения, не храните его в репозитории.

Адрес содержит токен — относитесь к нему как к паролю. В следующих версиях подключение перейдёт на OAuth.

## Безопасность

- Агент видит только то, что разрешено пользователю 1С. Права настраиваются в 1С, а не в облаке.
- Расширение не пишет в проведённые документы и регистры.
- Нашли уязвимость — напишите на security@bilem.ai, не в публичные issues.
